# Strony SEO — Cybereyeagency

Landing page pozycjonowania („SEO w 2026") w jednolitej estetyce radaru /
centrum dowodzenia, przygotowany osobno pod każde miasto.

Start: [`index.html`](index.html) — hub linkujący do wszystkich miast.

Każda strona to samodzielny plik HTML bez zależności zewnętrznych (obsługa
motywu jasnego/ciemnego, responsywność, dostępność), gotowy do otwarcia w
przeglądarce lub wdrożenia na hosting statyczny.

## Uwagi

- Sekcja lokalna jest uniwersalna („zasięg lokalny": centrum / osiedla /
  okolice / region), bez wymyślania konkretnych dzielnic dla każdego miasta.
- Dane kontaktowe (`kontakt@cybereyeagency.pl`, numer telefonu) są
  placeholderami — do podmiany na prawdziwe.
- Nazwy miast zapisano w poprawnej polskiej pisowni; skorygowano literówki z
  zamówienia: Hojnówka → Hajnówka, Półtusk → Pułtusk, Grjewo → Grajewo.
